# 🎮 TRIØ — Rock Paper Scissors

TRIØ is my second game project, built using **HTML, CSS, and JavaScript**.
It's a modern and interactive version of the classic **Rock Paper Scissors** game, created while learning JavaScript through **Apna College and Shraddha Ma'am's lectures**.
This project helped me practice JavaScript concepts like:

- DOM Manipulation
- Event Listeners
- Functions
- Conditional Logic
- User Input
- Dynamic Score Updates
- Game Logic
It may be a simple game, but building it from scratch helped me understand how JavaScript can make a webpage interactive and actually *feel like an application*. 🚀

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

This project is part of my journey of learning **JavaScript and Web Development**, where I'm trying to turn each concept I learn into something I can actually build.

**Built with curiosity, code & a little bit of chaos. 🖤**
